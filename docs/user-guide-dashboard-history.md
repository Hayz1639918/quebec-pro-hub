# 📖 Guide Utilisateur - Historique du Dashboard

## 🎯 Introduction

Ce guide vous explique comment utiliser les nouvelles fonctionnalités d'historique du dashboard client de BâtirNet.

---

## 📋 Accéder au Dashboard

1. **Connectez-vous** à votre compte client sur BâtirNet
2. Cliquez sur **"Dashboard"** dans le menu ou allez sur `/dashboard`
3. Vous verrez maintenant **7 onglets** au lieu de 4

---

## 🏗️ Onglet "Projets" - Gérer Vos Projets

### Voir Tous Vos Projets

1. Cliquez sur l'onglet **"Projets"**
2. Vous verrez la liste complète de tous vos projets

### Informations Affichées

Pour chaque projet, vous verrez :
- 📝 **Titre et description** du projet
- 🏷️ **Statut** : Badge coloré (Ouvert, En cours, Complété, Annulé)
- 💰 **Budget** : Fourchette de prix ou "À discuter"
- 📍 **Localisation** : Ville et région
- 🏗️ **Catégorie** : Type de travaux
- 📅 **Dates** : Création et échéance
- 💬 **Propositions** : Nombre de propositions reçues
- 👁️ **Vues** : Nombre de fois que le projet a été consulté

### Actions Disponibles

Pour chaque projet, cliquez sur le menu **"..."** pour :

#### 🔍 Voir les Détails
- Affiche la page complète du projet
- Vous redirige vers la marketplace des projets

#### ✏️ Modifier
- ⚠️ Fonctionnalité à venir
- Permettra de modifier le titre, budget, description, etc.

#### 🗑️ Supprimer
1. Cliquez sur "Supprimer"
2. Confirmez dans la boîte de dialogue
3. ⚠️ **Attention** : Cette action est irréversible !
4. Le projet et toutes ses propositions seront supprimés

### Créer un Nouveau Projet

1. Cliquez sur le bouton **"+ Nouveau"** en haut à droite
2. Remplissez le formulaire
3. Cliquez sur **"Publier le projet"**
4. Le projet apparaît immédiatement dans la liste

### Exporter en PDF

1. Cliquez sur le bouton **"Export PDF"** en haut à droite
2. Une nouvelle fenêtre s'ouvre avec un aperçu
3. Utilisez **Ctrl+P** (ou Cmd+P sur Mac) pour imprimer
4. Ou choisissez **"Enregistrer en PDF"** dans les options d'impression

**Le PDF contient** :
- Logo BâtirNet
- Vos informations (nom, email)
- Date d'export
- Liste détaillée de tous vos projets
- Mise en page professionnelle

---

## 📊 Onglet "Activité" - Suivre Votre Historique

### Voir Votre Timeline

1. Cliquez sur l'onglet **"Activité"**
2. Vous verrez toutes vos actions chronologiques

### Types d'Activités

Chaque action sur la plateforme est enregistrée :

| Icône | Type | Description |
|-------|------|-------------|
| ➕ Vert | Projet créé | Vous avez créé un nouveau projet |
| ✏️ Bleu | Projet mis à jour | Vous avez modifié un projet |
| 🗑️ Rouge | Projet supprimé | Vous avez supprimé un projet |
| 💬 Violet | Proposition reçue | Un professionnel vous a envoyé une offre |
| 📄 Indigo | Contrat signé | Vous avez signé un contrat (futur) |
| 💳 Vert émeraude | Paiement effectué | Vous avez validé un paiement (futur) |
| ⭐ Ambre | Évaluation postée | Vous avez noté un professionnel (futur) |

### Informations Affichées

Pour chaque activité :
- 📅 **Date relative** : "il y a 2 heures", "il y a 3 jours"
- 📝 **Description** : Détails de l'action
- 📊 **Métadonnées** : Informations contextuelles
  - Nom du projet concerné
  - Nom du professionnel (pour propositions)
  - Montant (pour paiements)
- 🕐 **Date complète** : En bas (ex: "21 octobre 2025 à 14:30")

### Exporter en PDF

1. Cliquez sur le bouton **"Export PDF"** en haut à droite
2. Une nouvelle fenêtre s'ouvre avec la timeline
3. Enregistrez ou imprimez

## ❓ Questions Fréquentes

### Q: Puis-je modifier un projet après l'avoir créé ?

**R:** Pas encore. La fonctionnalité d'édition arrive bientôt. Pour l'instant, vous pouvez supprimer et recréer le projet.

### Q: Les propositions sont-elles supprimées avec le projet ?

**R:** Oui. Quand vous supprimez un projet, toutes les propositions associées sont également supprimées. C'est irréversible.

### Q: Comment sauvegarder mes projets ?

**R:** Utilisez le bouton **"Export PDF"** pour avoir une copie de tous vos projets en format PDF.

### Q: Combien de projets puis-je créer ?

**R:** Illimité ! Vous pouvez créer autant de projets que vous le souhaitez.

### Q: Les professionnels voient-ils toutes mes actions ?

**R:** Non. Votre timeline d'activité est **privée**. Les professionnels voient uniquement :
- Les projets que vous publiez
- Les messages que vous leur envoyez

### Q: Comment être notifié d'une nouvelle proposition ?

**R:** Les notifications par email arrivent bientôt. En attendant, consultez régulièrement votre onglet "Propositions".

### Q: Puis-je exporter ma timeline en Excel ?

**R:** Pas encore. Actuellement, seulement l'export PDF est disponible. L'export Excel est prévu pour plus tard.

## 🆘 Aide et Support

### Problème d'Affichage

Si les projets ne s'affichent pas :
1. Vérifiez que vous êtes bien connecté
2. Actualisez la page (F5)
3. Vérifiez votre connexion internet
4. Essayez de créer un nouveau projet

### Erreur lors de la Suppression

Si un projet ne se supprime pas :
1. Actualisez la page
2. Réessayez
3. Si le problème persiste, contactez le support

### Export PDF ne Fonctionne Pas

1. Autorisez les pop-ups dans votre navigateur
2. Vérifiez que JavaScript est activé
3. Essayez avec un autre navigateur (Chrome recommandé)

### Contact Support

Si vous rencontrez un problème :
- 📧 Email : support@batirnet.ca
