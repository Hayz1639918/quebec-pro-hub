# Roadmap — BâtirNet

## Phases
- MVP (Québec)
  - Profils pros, recherche/filtres, création de projet
  - Contrats standards + e‑signature
  - Paiements par jalons (Stripe)
  - Évaluations multi‑critères
  - Multilingue FR/EN, sécurité (2FA, audit), conformité de base (PIPEDA)
- Extension Canada
  - Vérifs provinciales étendues (RBQ/assurances/permis)
  - Analytique & dashboards
  - Offre VIP client (accompagnement)
- USA/Europe
  - Localisation juridique, moyens de paiement
  - Internationalisation avancée, conformité (ex: GDPR)

## Évolutions techniques
- IA matching: itérations sur modèles, signaux de réputation, disponibilité.
- Microservices: scalabilité, tolérance aux pannes, observabilité.
- Data: entrepôt analytique, pipelines ETL/ELT.
- Sécurité: durcissement WAF, gestion clés KMS, rotation secrets.
